# Security policy

## Reporting a vulnerability
Please report vulnerabilities privately to jesse@kleinekoe.nl. Do not open a public issue and do not include exploit details in public places.

## Response
We aim to acknowledge a report within 7 days and to fix or publish an advisory within 90 days.

## Scope
In scope: the `guard/` package, its HTTP API and the evaluation scripts in this repository.
Out of scope: third-party models, Ollama, and the third-party tools listed in `THIRD-PARTY.md` (report those to their maintainers).
